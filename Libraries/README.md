# Libraries

A set of self-contained libraries that provide the reusable functionality of the project.

## Overview

| Library | Description |
| --- | --- |
| `UserManagement` | Handles user management in a database. |
| `yourvrxp-ai` | Interacts with a backend AI. |
| `yourvrxp-analytics` | Registers events used for analytics in the database. |
| `yourvrxp-narration` | Handles the narration system. |
| `yourvrxp-networking` | Handles networking operations. |
| `yourvrxp-social` | Handles operations with social network providers. |
| `yourvrxp-speech` | Handles speech recognition and speech generation through Google. |
| `yourvrxp-utils` | A collection of scripts for various purposes. |
| `yourvrxp-voice` | Handles voice streaming. |
| `yourvrxp-vr` | Manages the VR functionality. |

## Dependencies

The main project (`Assets/Application/AppMuseum`) uses all of these libraries.

> [!NOTE]
> None of the libraries reference the main project in return, so you should be able to extract any of them and use them in other projects.
